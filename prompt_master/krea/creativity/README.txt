KREA 2 CREATIVE MODE STARTER LIBRARY

Data-only starter package for the local Creative Director.
Variant families included: 164

Rules:
- Natural: omit the axis from the Creative Direction.
- Vary: choose locally from the axis file; master Creativity controls activation
  count, eligibility, expression tier, and anti-repetition.
- Fixed: reuse the selected variant ID unless the user's source prompt conflicts.
- Creativity 2-3 -> light expression.
- Creativity 4-6 -> moderate expression.
- Creativity 7-8 -> strong expression.
- Creativity 9-10 -> extreme expression.
- Creativity 10 normally activates every eligible Vary axis.
- Explicit user constraints always win.
- The library is selected locally and requires NO LLM call.
- One Creative roll must make exactly ONE Krea writer call after local selection.

Stable IDs should not be renamed after release because saved Fixed selections may
reference them.
