Krea 2 repository. It is the file Krea's prompting guide points at: "If you
wish to use LLM assistance for generating longer prompts, check out
expansion.txt and use it as a system prompt for LLM of your choice."
(docs/prompting.md, same repository.)

# attribution and licensing
The Krea 2 weights are released under Krea's community licence
(https://www.krea.ai/krea-2-licensing); the repository's docs, this file among
them, are published there as the prompting guidance for those weights. It is
vendored rather than fetched so that a prompt written here does not depend on a
network call (design intent §14), and it is reproduced in full and unmodified
with its origin recorded above.

Nothing else in this package is Krea's. The reference-image addendum, the
caption instruction, the sampling numbers and the labelled user turn in
enhancer.py are this extension's own, and enhancer.py says so beside each of
them. The "Image 1 / Image 2" convention in particular is an LLM Studio
convention: Krea does not document it, and this extension does not present it
as Krea syntax.
