prompt_enhancer.py is a byte-for-byte copy of the file of that name in the
MiniMax H3 module written for WanGP (github.com/deepbeepmeep/Wan2GP). It was
supplied as minimax_h3.zip rather than fetched from a checkout, so there is no
commit to pin and the content is pinned instead.

how the image becomes a caption, what the user turn looks like and what the
sampler is set to — are ported from WanGP itself, at these call sites:

The values those call sites decide are quoted in enhancer.py beside the
constants they became. Where this port departs from WanGP it says so in the
module docstring; there is one departure, and it is about newlines.
